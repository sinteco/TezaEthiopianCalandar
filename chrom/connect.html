Setup help / የማዋቀሪያ እገዛ

The OAuth client must have application type Chrome Extension and its Item ID must match the extension ID shown at chrome://extensions. Enable Google Calendar API in the same Google Cloud project, and add your Google account as a test user if the consent screen is in Testing mode.

Both calendar-list and event read permissions are required. See the extension README for full setup instructions.
