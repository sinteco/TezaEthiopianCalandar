# Ethiopian Calendar — Privacy Policy

This repository hosts the privacy policy for the **Ethiopian Calendar** Chrome extension.

- [PRIVACY.md](./PRIVACY.md) — the policy

## Publishing with GitHub Pages

1. Push this folder to a public GitHub repository (e.g. `ethiopian-calendar-privacy`).
2. In the repository: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
3. After about a minute the policy is live at
   `https://<your-username>.github.io/<repository-name>/`
   (`index.md` is served as the home page; `PRIVACY.md` is the same text).
4. Paste that URL into the Chrome Web Store dashboard under **Privacy practices → Privacy policy URL**.

If you do not want to enable Pages, the raw file URL also works:
`https://github.com/<your-username>/<repository-name>/blob/main/PRIVACY.md`
